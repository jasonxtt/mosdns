# v0.7.3

## Summary

This release adds upstream management inside dedicated routing groups.

- a dedicated group can reference an entire existing upstream group or one
  upstream from that group
- a dedicated group can add and manage ordinary upstreams owned only by that
  group
- source references are refreshed when their upstream state changes, and
  invalid references are surfaced as warnings and excluded from runtime use
- the dedicated-group editor now presents these settings in a compact,
  responsive layout that follows the existing glass/transparent UI theme

## Compatibility boundary

This is a binary/UI and runtime-state update. The configuration structure
remains schema `4` with package ID `main-config-schema-4`; no external
`config_up.zip` or `config_all.zip` update is required.
