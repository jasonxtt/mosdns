# v0.7.2

## Summary

This release fixes the priority of dedicated upstream groups for domains that
also match the DDNS suffix list.

- `sequence_6666` and `sequence_requery` now invoke the dedicated-group
  dispatcher before the DDNS branch and ordinary routing.
- generated special-group configuration now contains one shared
  `sequence_special` dispatcher instead of separate v4, v6, and other-query
  wrappers.
- the per-group `sequence_special_<slot>` sequences remain unchanged and still
  provide the actual dedicated upstream handling.

## Compatibility boundary

`v0.7.2` upgrades the configuration structure to schema `4` and package ID
`main-config-schema-4`. Existing installations on schema 3 must apply the
matching `config_up.zip` during the binary update transaction. The release
metadata pins and verifies that external package before publishing the update
manifest.
