S1 adds opt-in state schema, strict enabled local-text input, disabled opaque
record retention, standard DNS override conversion, generated native sequences
and snapshot-local router/provider/child identities, listener inventory and CNAME
normalization. Generated bytes are the compiler input and carry their SHA-256.
The legacy aliapi wrapper can describe standard DNS entries; signed entries remain
rejected by the native forward compiler. Custom TCP listeners declare the existing
Go default ten-second connection idle timeout (not upstream idle timeout).
Generated providers are immutable; until S2 installs the supervisor, assembly
refuses multiple listeners rather than starting a partial host. Management/UI and
transaction/recovery guarantees are later slices and are not yet advertised.
