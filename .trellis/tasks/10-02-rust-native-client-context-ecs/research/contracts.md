- query_context/context.go NewContext swaps client OPT for a new outbound OPT and makes separate respOpt only for EDNS client. Native currently sends original query, so copying Go early-return verbatim would bypass forward/preset/send. - native cache.rs query_edns rejects ECS; compile_cache rejects true, prepare_import demands no suffix. These safety defaults remain for false/quick, true explicitly extends key/codec support.
- Go cache.go getECSClient uses first current QOpt ECS.String, appends one length byte+string. miekg/dns String emits IPv4 x/m/s or IPv6 [x]/m/s; pack masks/truncates address to source prefix. Generated Go ECS may keep host bits in the prepack String. Canonical network key/import versus exact logical String must be explicitly reviewed; cannot silently claim both canonical merging and byte-identical Go runtime keys.
